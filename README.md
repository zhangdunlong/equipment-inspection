# 设备点检巡检系统（开源脱敏版）  ·  当前版本 v1.45.0

一套**零依赖**的设备点检 / 巡检管理系统：支持设备台账、按日 / 按月点检、电子签名确认、温湿度监测记录、独立检查项目、**数据定时备份**与月度打印归档。前端与后端同源一体，可部署到云端、自有服务器，也可单机离线运行。

> 适用场景：工厂、实验室、物业等仪器的日常点检、月度巡检与签名确认。

## 功能（v1.45.0）

- **设备台账**：设备编号、名称、型号、所属点检模板、所在房间。（演示数据 **48 台设备 / 12 个房间 / 9 套模板**，按 6 个分组铺满大屏）
- **点检模板**：可配置点检项目（内容 + 频次），支持复制 / 导入。
- **点检作业与大屏**：按设备每日点检、状态大屏、按日 / 按月查看。
- **电子签名**：点检完成后由授权签名人签名（演示数据不含真实签名图片）；签名下拉默认选中登录人本人。
- **月度点检表**：按房间 / 设备生成月度点检汇总与打印视图（打印排版自适应，长检查项不裁切）。
- **温湿度监测记录**：房间温湿度填录、一键填充、划线、报警配置与告警；支持「湿度：≤70%RH」与「湿度：40~70%RH」两种写法，区间写法会同时判定上下限；每个房间还可单独设**专属范围**（优先于全局范围与房间要求）。
- **温湿度表头设备清单**：后台支持多行录入，表头行高随设备条数自动撑开，超长清单不再被静默截断。
- **数据定时备份**（新增）：把全量数据**定时自动落盘**到本机指定文件夹，`年/月` 自动分层归档，并同时落一份含密钥的配套配置（缺它则密码校验对不上、等于无法还原）。
  - **多目标互为副本**：最多 8 个目标文件夹，同一份数据**一次性序列化后同时写到每一处**（各副本逐字节一致），单个盘不可用不连累其他盘；部分成功会在后台逐条列出是哪个目标没写成、为什么。
  - **逐目标频率**：每个目标可各配一套 `每周 / 每天 / 每隔 N 小时 / 每月` + 时刻 + 保留份数；判重台账按目标分别落盘，跨重启有效；只有成功才封该目标的周期。
  - **安全写入**：先写 `.tmp` 再 `rename`（断电不会留下半截文件）；写前检查磁盘余量；可重试类错误按 3s/6s/9s 退避重试，路径无效或权限不足则立即失败并写运行日志。
  - **可视化**：后台「💾 数据备份」页签显示逐目标策略 / 可写状态 / 磁盘余量 / 下次执行 / 已生成文件清单 / 执行历史，并写明还原步骤。
- **独立检查项目（programs）**：与常规点检分离的专项检查表（如摩擦风阻损耗检查、显微镜维护记录）。
- **检查记录（checkRecords）**：独立项目的按日期 / 周次记录；周检项目支持手动改期（行身份仍是周一，仅覆盖显示日期）。
- **通知（notifs）** 与 **细粒度权限**：按人开放点检模板管理、温湿度录入、批量操作、导出等。
- **表单页眉统一配置**：温湿度 / 设备点检 / 专项检查 / 批量打印四档页眉（表单编号 + 版本）后台统一维护，并支持**房间级覆盖**；解析优先级为「后台配置 > 载体自带（模板/检查表）> 内置默认」，未配置档位留空即走默认。
- **打印与可读性**：打印线宽全站收敛为**三档**（外框 4.5pt / 表格内线 2.5pt / 表单填写横线 1.5pt），覆盖温湿度、设备点检、批量打印、月报、专项检查 5 个页面；温湿度表一页装得下、页眉不再独占首页；下拉选项显式配色（暗色页与白底页分别声明），全站文本对比度按 WCAG 实算达标。
- **温湿度数据校验**：写入侧只接受数值（非法值清空并 `rejected` 回报 + 前端 toast 列出具体格子），输入时即剔除非法字符；温度与湿度统一按一位小数写入与显示（`58.3333 → 58.3`，整数不补零）。
- **顶栏「外部系统」快捷跳转**：LIMS / 力学工具箱 / BPM 等外部系统一键跳转，条目与**可见科室**在后台可配（科室为空 = 所有登录人员可见）。
- **操作手册入口**：顶栏「📖 操作手册」可在后台配置是否显示，手册本体由系统以 `/manual` 托管（开源版为中性说明页）。
- **界面改版**：大屏卡片状态徽章与图例、一键点检整行「正常/异常」滑块与实时计数、管理后台页签四组分组、温湿度工具栏（段式选择器 + 常驻保存/打印 + 「更多操作 ▾」收纳）。
- **移动端适配**：设备大屏 / 房间 / 点检作业用新版导航（自带折叠菜单）；温湿度 / 专项检查 / 管理后台这几页用的是旧版顶栏，本次补齐了 ≤760px 的折叠菜单 —— 补之前它们在窄屏会把顶栏文字压成竖排、**并把布局视口撑宽到 417px**（整页横向溢出）。
- **LIMS 对接 / 局域网远程升级**：保留接口结构，凭据与地址均为占位符（`<LIMS_BASE_URL>` 等），默认关闭。LIMS 湿度抓取会**自动按 ≤20 天分段串行拉取后合并**——LIMS 的 `humidityChart` 接口限制单次查询跨度不超过 23 天，整月一次拉取必然被拒（`code=5004 时间间隔过长`）。

## 快速开始

### Node 服务版
```bash
cd equipment-inspection-server
npm install
node server.js     # 默认监听 http://localhost:8787
```

### Windows 便携版
直接双击 `启动.bat`（`node server.js` 免安装），或：
```bat
cd equipment-inspection-win10
启动.bat
```

### 在线演示站（只读）
见上方 Live Demo 地址。该站点为只读展示：**可登录浏览后台，但不能写入任何数据**。

| 行为 | 演示站 | 说明 |
|------|--------|------|
| 浏览页面 / 查询数据 | ✅ 允许 | 全部 GET 接口对访客开放 |
| 登录后台 | ✅ 允许 | `admin` / `admin123`、`demo-user` / `demo123` |
| 新增 / 编辑 / 删除 / 导入 / 备份恢复 / 一键操作 | ❌ 拒绝 | 服务端 `403 {readonly:true}`，前端同时隐藏入口 |
| 整库导出 `/api/admin/backup`（含密钥与口令哈希） | 🔒 需登录 | 未登录返回 401 |
| 「💾 数据备份」页签（配置 / 历史 / 文件清单） | 👁 只读 | 可查看配置与历史；目标文件夹的**可写状态与磁盘余量如实显示为不可用**（Serverless 运行环境没有文件系统，不做假） |

> 自行部署 Pages 版时，`pepper` / `secret` 的取值优先级为：**KV 内的固化值 → 环境变量 `APP_PEPPER` / `APP_SECRET` → 本次请求随机**。
> 前两者都不存在时会退化为每次请求随机生成，口令校验将永远无法通过，**务必固化其中之一**（演示站已把演示值写入 KV）。
>
> ⚠️ 演示数据里 `backup.enabled` 刻意是 **`false`**：`sample.kv.json` 是**三套版本共用**的种子数据，若默认开启，任何人 clone 下来跑一次 Node 版就会真的往目标文件夹写备份。配置项照常填满（两个目标、逐目标频率），需要时在后台打开开关即可。

## 目录结构
```
equipment-inspection-opensource/
├── README.md / LICENSE / 功能说明.md / 更新日志.md / version.json
├── equipment-inspection/      Cloudflare Pages 演示站（只读）
│   ├── *.html                 前端页面（已去品牌）
│   ├── assets/                静态资源（已移除品牌图片）
│   ├── functions/[[path]].js  只读后端（Pages Functions）
│   ├── wrangler.toml          占位配置（KV 绑定请在本机 Pages 项目设置里配）
│   └── data/sample.kv.json    演示数据种子
├── equipment-inspection-server/  Node 服务版（完整功能）
└── equipment-inspection-win10/   Windows 便携版（完整功能）
```

> ⚠️ `equipment-inspection/wrangler.toml` 里的 KV 命名空间 ID 是**占位符** `<YOUR_KV_NAMESPACE_ID>`。
> 部署前请先在本机新建一个 KV 命名空间并填入真实 ID；**不要把填了真实 ID 的 `wrangler.toml` 一起上传为静态资源**
> ——Pages 会把项目根目录的文件一并发布，`https://<你的域名>/wrangler.toml` 会直接泄露该 ID。
> 若 KV 绑定已固化在 Pages 项目设置中（推荐），部署时**不必**携带该文件。
