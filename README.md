# 设备点检巡检系统（开源脱敏版）  ·  当前版本 v1.37.1

一套**零依赖**的设备点检 / 巡检管理系统：支持设备台账、按日 / 按月点检、电子签名确认、温湿度监测记录、独立检查项目与月度打印归档。前端与后端同源一体，可部署到云端、自有服务器，也可单机离线运行。

> 适用场景：工厂、实验室、物业等仪器的日常点检、月度巡检与签名确认。

## 功能（v1.37.1）

- **设备台账**：设备编号、名称、型号、所属点检模板、所在房间。
- **点检模板**：可配置点检项目（内容 + 频次），支持复制 / 导入。
- **点检作业与大屏**：按设备每日点检、状态大屏、按日 / 按月查看。
- **电子签名**：点检完成后由授权签名人签名（演示数据不含真实签名图片）；签名下拉默认选中登录人本人。
- **月度点检表**：按房间 / 设备生成月度点检汇总与打印视图（打印排版自适应，长检查项不裁切）。
- **温湿度监测记录**：房间温湿度填录、一键填充、划线、报警配置与告警；支持「湿度：≤70%RH」与「湿度：40~70%RH」两种写法，区间写法会同时判定上下限。
- **温湿度表头设备清单**：后台支持多行录入，表头行高随设备条数自动撑开，超长清单不再被静默截断。
- **独立检查项目（programs）**：与常规点检分离的专项检查表（如摩擦风阻损耗检查、显微镜维护记录）。
- **检查记录（checkRecords）**：独立项目的按日期 / 周次记录；周检项目支持手动改期（行身份仍是周一，仅覆盖显示日期）。
- **通知（notifs）** 与 **细粒度权限**：按人开放点检模板管理、温湿度录入、批量操作、导出等。
- **表单页眉统一配置**：温湿度 / 设备点检 / 专项检查 / 批量打印四档页眉（表单编号 + 版本）后台统一维护，并支持**房间级覆盖**；解析优先级为「后台配置 > 载体自带（模板/检查表）> 内置默认」，未配置档位留空即走默认。
- **打印与可读性**：温湿度表打印页眉回正页（一页装得下，不再出现页眉独占首页）；下拉选项显式配色（暗色页与白底页分别声明），全站文本对比度按 WCAG 实算达标。
- **顶栏「外部系统」快捷跳转**：LIMS / 力学工具箱 / BPM 等外部系统一键跳转，条目与**可见科室**在后台可配（科室为空 = 所有登录人员可见）。
- **操作手册入口**：顶栏「📖 操作手册」可在后台配置是否显示，手册本体由系统以 `/manual` 托管（开源版为中性说明页）。
- **界面改版**：大屏卡片状态徽章与图例、一键点检整行「正常/异常」滑块与实时计数、管理后台页签四组分组、温湿度工具栏（段式选择器 + 常驻保存/打印 + 「更多操作 ▾」收纳）。
- **LIMS 对接 / 局域网远程升级**：保留接口结构，凭据与地址均为占位符（`<LIMS_BASE_URL>` 等），默认关闭。

## 快速开始

### Node 服务版
```bash
cd equipment-inspection-server
npm install
node server.js     # 默认监听 http://localhost:8787
```

### Windows 便携版
直接双击 `启动.bat`（`node server.js` 免安装），或：
```bat
cd equipment-inspection-win10
启动.bat
```

### 在线演示站（只读）
见上方 Live Demo 地址。该站点为只读展示：**可登录浏览后台，但不能写入任何数据**。

| 行为 | 演示站 | 说明 |
|------|--------|------|
| 浏览页面 / 查询数据 | ✅ 允许 | 全部 GET 接口对访客开放 |
| 登录后台 | ✅ 允许 | `admin` / `admin123`、`demo-user` / `demo123` |
| 新增 / 编辑 / 删除 / 导入 / 备份恢复 / 一键操作 | ❌ 拒绝 | 服务端 `403 {readonly:true}`，前端同时隐藏入口 |
| 整库导出 `/api/admin/backup`（含密钥与口令哈希） | 🔒 需登录 | 未登录返回 401 |

> 自行部署 Pages 版时，`pepper` / `secret` 的取值优先级为：**KV 内的固化值 → 环境变量 `APP_PEPPER` / `APP_SECRET` → 本次请求随机**。
> 前两者都不存在时会退化为每次请求随机生成，口令校验将永远无法通过，**务必固化其中之一**（演示站已把演示值写入 KV）。
