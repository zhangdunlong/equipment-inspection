# 设备点检巡检系统 · Win10 便携版

> 一套**双击即用**的设备点检巡检系统，专为在没有开发环境的普通 Windows 10 电脑上运行而设计。
> 自带便携 Node.js 运行时，**无需安装任何软件**，拷到哪台 Win10 都能跑。

---

## 一、怎么用（三步）

1. 把整个 `equipment-inspection` 文件夹拷到目标 Win10 电脑（U 盘 / 微信 / 网盘均可）。
2. **双击 `启动.bat`**。
3. 浏览器自动打开 `http://localhost:8787/`，即可使用。

> 首次启动会自动在 `data/` 目录生成数据库文件，**之后所有点检数据都存在这台电脑上**。

## 二、默认账号

| 角色 | 账号 | 密码 |
|------|------|------|
| 管理员（后台） | `admin` | `admin123` |
| 点检员（操作员） | 在「管理后台 → 签名人员」中创建，各自有独立签名密码 | —— |

> 首次登录管理员后，请务必到「管理后台 → 修改密码」改掉默认密码。

## 三、目录结构

```
equipment-inspection/
├── 启动.bat              # 双击启动（自动开浏览器）
├── server.js             # 零依赖 Node 服务（前端 + 后端一体）
├── runtime/
│   └── node.exe          # 自带便携 Node 运行时（无需安装）
├── public/               # 前端页面
│   ├── index.html        # 设备大屏
│   ├── admin.html        # 管理后台
│   ├── inspect.html      # 点检作业
│   ├── monthly.html      # 月度点检表
│   ├── print-all.html    # 整月打印
│   └── assets/style.css
└── data/
    └── kv.json           # 运行时自动生成的数据库（含设备/签名人/点检记录）
```

## 四、常见问题

- **换端口**：用记事本打开 `启动.bat`，把 `set "PORT=8787"` 改成别的（如 `9000`），保存后重开。访问地址相应改为 `http://localhost:9000/`。
- **换电脑 / 备份数据**：直接把整个文件夹拷走即可，`data/kv.json` 包含了全部数据。建议定期备份 `data/` 文件夹。
- **多台电脑共享数据？** 本便携版数据存在本地。若要多地共享，请改用「服务器部署版」或原 Cloudflare 版。
- **杀毒软件拦截？** `node.exe` 是官方 Node.js 运行时，可能被误报，加入白名单即可。
- **双击后浏览器显示“无法访问此网站”？**
  1. 看任务栏或桌面有没有弹出黑色的「设备点检系统服务」窗口；如果没有，通常是杀毒软件/360 拦截了 `node.exe`，请把 `runtime\node.exe` 加入白名单后重试。
  2. 也可以手动启动排查：按住 `Shift` 在文件夹空白处点右键 →「在此处打开 PowerShell 窗口」或「终端」，输入：
     ```powershell
     .\runtime\node.exe .\server.js
     ```
     如果看到 `设备点检巡检系统 已启动`，说明服务正常，再访问 `http://localhost:8787/` 即可。
- **关不掉服务？** 关闭弹出的「设备点检系统服务」黑色窗口即可彻底停止。

## 五、与另外两版的关系

本项目由线上 Cloudflare Pages 版反推而来，提供三套交付：

| 版本 | 适用场景 | 是否需要联网 |
|------|----------|--------------|
| `equipment-inspection`（含 `functions/`） | 原 Cloudflare Pages 部署版 | 部署后联网访问 |
| `equipment-inspection-server` | 部署到自有 Linux/Windows 服务器 | 局域网/公网访问 |
| **`equipment-inspection`（本目录）** | **单机离线 / 车间电脑，双击即用** | **纯本地，无需联网** |

三套版本的**前端页面与后端接口完全一致**，数据格式互通（`data/kv.json` 与 Cloudflare KV 的 key 结构相同）。
