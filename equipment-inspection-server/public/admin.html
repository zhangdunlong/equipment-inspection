💾 数据备份 / 导出

备份建议每月一次，下载的 JSON 即完整数据库快照，可整份替换 data/kv.json 恢复。CSV 含全部点检记录（编号/名称/房间/日期/时间/结果/备注），带 BOM 可直接用 Excel 打开。

🔗 关于

🐙 GitHub 主页 设备点检巡检系统 · Node.js 零依赖 · 数据存于 data/kv.json

整月一键点检为管理员操作：选择月份、设备范围（按房间 / 指定单台 / 全部设备）与登记签名人，将所选设备整月标记为「正常」并套用该签名人的电子签名（电子签名仅能在后台上传）。可指定「截止日期」，避免提前点检未到的日期。「取消 / 删除」在指定单台时，还能一键清掉这台设备之前所有月份的点检数据与签名。

默认截止到今天，仅点检 1 日至该日的日期
